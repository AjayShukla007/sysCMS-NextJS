# sysCMS-NextJS: Easily Interact with Your APIs

**What is sysCMS?**

Think of sysCMS as a control panel for your web APIs (Application Programming Interfaces). APIs are how different software components talk to each other to get or send information.

SysCMS provides a simple web interface where you can:

1. **Define Your API Connections:** Tell sysCMS the web address (URL) and method (like GET to fetch data, or POST to send data) for each API endpoint you want to interact with.
2. **Specify Data Fields:** Define what information needs to be sent to the API (like user input for a form, search terms, or configuration settings). SysCMS helps you create the necessary input fields (text boxes, checkboxes, etc.).
3. **Test Your APIs:** Use the forms generated by sysCMS to easily send requests to your defined API endpoints and see the response directly in your browser. This is great for testing if your APIs are working correctly or for triggering actions manually.
4. **Manage Sensitive Information:** Store things like API keys or secret tokens securely as environment variables, which you can then easily reference when setting up your API requests.

**Who is it for?**

* **Developers:** Quickly test and debug backend APIs without writing extra code or using complex tools.
* **Content Managers/Non-Developers:** Interact with specific APIs (e.g., to publish content, update data) through a user-friendly interface without needing deep technical knowledge.

**Flexible and Customizable:**

SysCMS is designed to be simple and adaptable.
**No External Dependencies:** It relies only on your browser's local storage, meaning there are no complex databases or external services to set up.
**No Limits:** Define as many API routes and fields as you need.
**Customize It:** Because it's built with standard web technologies (Next.js, React, Tailwind CSS), you can easily modify and extend it to fit your specific requirements.

**How to Use It:**

1. Navigate to the dashboard.
2. Add a new "Route" by providing the API's URL, method, and defining the required input fields (headers, query parameters, body data).
3. Go to the specific route's page.
4. Fill in the generated form with the data you want to send.
5. Click the "Send" or "Test" button.
6. View the API's response (both data and status code) displayed on the page.
7. Manage environment variables separately in the "Environment Variables" section.

In short, sysCMS simplifies the process of connecting to and interacting with your APIs directly from a web interface
